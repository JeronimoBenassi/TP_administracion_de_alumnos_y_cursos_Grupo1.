# TP_administracion_de_alumnos_y_cursos_Grupo1.


Descripción del sistema: El sistema de Administración de Alumnos y Cursos tiene como objetivo gestionar la información de alumnos, cursos y las inscripciones realizadas. Permitirá administrar los datos principales de los alumnos y cursos, registrar las inscripciones y consultar información mediante diferentes reportes.

Entidades principales:

Alumno: DNI, nombre, apellido, fecha de nacimiento, email y teléfono.
Curso: nombre, descripción, duración, cupo máximo y estado.
Inscripción: relaciona un alumno con uno o muchos cursos y registra la fecha de inscripción y el estado de la inscripción.


Objetivos y funcionalidades previstas:

El sistema tendrá como objetivo facilitar la administración de alumnos y cursos, permitiendo registrar, modificar, eliminar y consultar información.



- Alta, baja y modificación:

El sistema contará con operaciones de alta, baja y modificación para diferentes entidades.

  ABM de Alumnos:

  Alta: registrar un nuevo alumno.
  Baja: eliminar o desactivar un alumno.
  Modificación: actualizar sus datos personales.

  ABM de Cursos

Alta: crear un nuevo curso.
Baja: eliminar o desactivar un curso.
Modificación: actualizar la información del curso.

---

- Reportes

El sistema contará con al menos los siguientes reportes:

1. Listado de alumnos: mostrar todos los alumnos registrados con sus datos principales.

2. Listado de cursos: mostrar todos los cursos disponibles y su información.

3. Alumnos inscriptos en un curso: seleccionar un curso y mostrar todos los alumnos que se encuentran inscriptos.

4. Cursos de un alumno: seleccionar un alumno y mostrar todos los cursos en los que está o estuvo inscripto.

5. Cantidad de alumnos por curso: mostrar cuántos alumnos están inscriptos en cada curso.

6. Cursos con cupos disponibles: mostrar los cursos que todavía tienen lugares disponibles.
